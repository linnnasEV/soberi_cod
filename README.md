# СобериКод — программируй играя

Бесплатная веб-платформа блочного программирования для детей 1–4 классов.

**Сайт: https://linnnasev.github.io/soberi_cod/**

Ребёнок собирает программу из цветных блоков, ведёт героя через лабиринт, снимает свой
«мультик» — и после уроков узнаёт, какие профессии похожи на то, что ему понравилось.
Учитель создаёт класс, раздаёт детям код из четырёх цифр и видит, кто что прошёл и
кому программирование по-настоящему интересно.

## Чем отличается

- **Главная — это Мастерская.** Ребёнок открыл сайт и сразу видит сцену и блоки:
  ни рекламного экрана, ни кнопки «начать». Всё, что написано для взрослого,
  уместилось в одну строку под шапкой и в раздел «О проекте».
- **Бесплатно и без регистрации.** Первый урок открывается из раздела «Уроки», email и
  пароли не нужны: дети входят по коду класса и «секретной картинке».
- **Показывает, а не объясняет.** При первом визите платформа сама собирает программу
  из двух блоков и запускает её, потом стрелка подсказывает, куда нажать. Пример
  можно пересмотреть кнопкой, а объяснение — послушать: браузер проговорит его вслух.
- **Работает на слабой технике.** Чистые HTML, CSS и JavaScript: ни сборки, ни
  фреймворков, ни внешних библиотек и шрифтов. Иконки — инлайновый SVG, звук
  синтезируется через Web Audio, медиафайлов нет вообще.
- **Работает без интернета.** После первого открытия сервис-воркер отдаёт всё из кэша,
  обновления догружаются в фоне.
- **Облегчённый режим** (переключатель в подвале) выключает анимации и ускоряет ходы
  героя — для совсем старых компьютеров. Рядом выключается звук: в классе за
  двадцатью компьютерами двадцать «та-да» одновременно — это шум, а не радость.
- **Виден не только результат, но и путь.** После урока ребёнок видит, сколько заданий
  курса пройдено, и получает значки за первые шаги; они же собраны в кабинете.
- **Мастерская — место без правильных ответов.** Шесть героев, шесть фонов, все блоки
  сразу и сцена, которую ребёнок собирает сам: ставит яблоки, цветы, камни и домик
  и переносит героя в любую клетку. Кнопка «Удиви меня» собирает случайную сценку —
  переделать готовое проще, чем придумать с нуля. Работы сохраняются в галерею вместе
  со сценой, и их видит весь класс.
- **Профориентация встроена в прогресс**: платформа показывает профессии, которые
  ребёнок уже «попробовал», и считает интерес по его реакциям после уроков.

## Как запустить

Сервис-воркеру нужен http(s), поэтому для полной проверки поднимите локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000. Можно просто открыть `index.html` с диска —
платформа работает, кроме офлайн-кэша.

Для показа без подготовки:

- **демо-класс для кабинета учителя** — код `1234`, ПИН `0000` (или кнопка
  «Открыть демо-класс»);
- **вход ребёнка** — код класса `1234`, затем своё имя и секретная картинка.

## Структура

```
index.html        все экраны платформы, подключение скриптов
manifest.json     PWA-манифест (установка как приложение)
sw.js             сервис-воркер: офлайн-режим, стратегия «сначала кэш»
css/style.css     вся вёрстка и темы фонов
js/icons.js       SVG-иконки, шесть героев, фоны, предметы для сцены
js/data.js        контент: курсы, уроки, карты, профессии, тест, достижения, демо-проекты
js/store.js       localStorage: профили, классы, ПИН, перенос класса файлом
js/sync.js        необязательная синхронизация класса через свой сервер
js/engine.js      разбор карты, проверка решения, анимация сцены, звук
js/editor.js      редактор блоков: палитра, курсор вставки, «Повтор», подсказки
js/ui.js          хеш-роутер, меню, окна, уведомления с кнопкой, облегчённый режим, звук, салют
js/lesson.js      экраны курсов и урока
js/studio.js      главная: сцена, предметы, сброс, сессия вкладки, галерея работ
js/auth.js        вход ученика, гостевые профили
js/teacher.js     кабинет учителя, статистика, печать карточек
js/pages.js       профессии, тест-опрос, кабинет ученика, «О проекте»
js/tour.js        первое знакомство: показ примера и подсказки-стрелки
server/app.py     необязательный сервер синхронизации (FastAPI + SQLite)
```

Скрипты подключены обычными тегами `<script>` в порядке зависимостей и общаются через
глобальные функции — так платформа открывается и с диска, без сборщика и модулей.

## Два уровня сложности

Курсы разделены на два трека полем `track` в `js/data.js`:

- **`junior` (1–2 класс)** — короткая подпись вместо абзаца, цепочка картинок
  `pic`, чтение задания вслух, маленькое поле, никаких лимитов на блоки.
  Понятные цели: домик, рыбка, цветок, а не абстрактная звезда.
- **`senior` (3–4 класс)** — циклы, лимиты блоков, относительные команды
  (`rel: true` рисует на сцене стрелку направления), вложенные повторы
  (`nested: true`) и блоки анимации.

Ребёнок без класса выбирает трек сам на главной. Классу трек достаётся
автоматически по классу, который учитель выбрал при создании.

## Как добавить урок

Уровень — это строки одинаковой длины в `js/data.js` (размер поля любой,
сцена подстраивается):

| Символ | Значение |
|--------|----------|
| `S`    | старт героя |
| `*`    | цель — звезда |
| `h`    | цель — домик |
| `f`    | цель — рыбка |
| `#`    | камень |
| `a`    | собрать: яблоко |
| `c`    | собрать: цветок |
| `.`    | пусто |

Новые виды клеток добавляются в `CELLS` в `js/engine.js` — туда же иконка
и признак `goal` или `collect`.

```js
{ id: 7, title: 'Новый урок',
  task: 'Что нужно сделать — текст для ребёнка.',
  hint: 'Подсказка по кнопке «?».',
  map: ['.......', '.......', 'S....*.', '.......', '.......'],
  blocks: MOVE,                                  // какие блоки в палитре
  maxBlocks: 2,                                  // необязательно: лимит блоков
  mustUse: ['repeat'],                           // необязательно: обязательные блоки
  preset: [{ t: 'right' }],                      // необязательно: программа с ошибкой
  solution: [{ t: 'repeat', n: 5, body: [{ t: 'right' }] }] }
```

Для младшего трека вместо длинного `task` пишется короткая подпись плюс
`pic` (цепочка иконок) и `say` — полное предложение, которое читается вслух:

```js
{ id: 9, title: 'Домой', task: 'Отведи домой', pic: ['home'],
  say: 'Птичка устала. Отведи её домой.',
  hint: 'Домик справа.',
  map: ['.....', 'S...h', '.....'],
  blocks: MOVE,
  solution: [{ t: 'right' }, { t: 'right' }, { t: 'right' }, { t: 'right' }] }
```

`solution` — эталон: по нему считаются звёзды за краткость программы и работают
подсказки, которые подсвечивают неверный блок. После добавления файла в `js/`
не забудьте дописать его в список `FILES` в `sw.js`.

## Данные и приватность

- По умолчанию всё хранится только в браузере устройства (`localStorage`, ключ
  `sobericod_v2`): ни один байт не уходит на сервер, внешних сервисов и аналитики нет.
  Единственное исключение — синхронизация, если учитель включил её сам (см. ниже).
- ПИН учителя хранится не открытым текстом, а отпечатком. Это защита от любопытного
  ребёнка, а не от взлома: данные класса всё равно лежат в браузере.
- Класс можно перенести на другой компьютер: в кабинете учителя — «Сохранить класс в
  файл» и «Загрузить класс из файла». При повторной загрузке прогресс объединяется,
  а не затирается. Файл выгрузки содержит имена детей — храните его как журнал.
- За одним компьютером может заниматься несколько детей: без входа в класс каждый
  заводит свой гостевой профиль («Кто сейчас играет?» в кабинете).

## Синхронизация между устройствами (необязательно)

Нужна, если класс занимается в двух кабинетах или ребёнок продолжает дома. Сама
платформа остаётся статическим сайтом: сервер — отдельная необязательная часть в
папке [`server/`](server/README.md), один файл на FastAPI и база SQLite.

```bash
cd server && pip install -r requirements.txt && uvicorn app:app --port 8000
```

Дальше в кабинете учителя — карточка «Синхронизация между устройствами»: адрес
сервера, кнопка «Включить синхронизацию» и ключ класса, который вводится на других
устройствах («Подключить устройство к классу»). Чтобы учителя не вводили адрес
руками, впишите его один раз в константу `SYNC_SERVER` в `js/sync.js`.

Что важно знать:

- Сервер не знает ничего об уроках: он хранит и выдаёт ту же выгрузку класса, что
  уходит в файл. Слияние делает браузер функцией `importClassJSON` — по каждому
  уроку остаётся лучший результат, поэтому порядок обмена не важен.
- Звёзды уходят сами после пройденного урока; кнопка нужна, только чтобы увидеть
  результат немедленно. Без интернета обмен просто откладывается.
- Одновременная запись с двух устройств не теряет данные: сервер отвечает `409`,
  браузер перечитывает, сливает и записывает снова.
- Ключ класса открывает журнал с именами детей. Это персональные данные: сервер
  нужен свой, под HTTPS, и ключ не стоит выкладывать в общий чат.
- Удаление ученика не разъезжается по устройствам: обмен только добавляет данные.

## Ограничения этой версии

- Без своего сервера прогресс не синхронизируется между устройствами
  автоматически — только файлом класса.
- Вложенные циклы в редакторе намеренно отключены: для 1–4 класса они лишние.
