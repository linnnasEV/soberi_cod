# Сервер синхронизации

Нужен только для одного: чтобы один класс открывался на нескольких устройствах.
Без сервера платформа работает как раньше — класс лежит в браузере и переносится файлом.

## Запуск

```bash
cd server
python -m venv .venv
.venv/Scripts/activate        # Linux и macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

Проверка: http://localhost:8000/api/health → `{"ok":true}`

База — файл `sync.db` рядом со скриптом, создаётся сам. Весь бэкап — копия этого файла.

## Подключение платформы

В кабинете учителя → «Синхронизация между устройствами» → вписать адрес сервера
(`http://localhost:8000` при локальной проверке, иначе `https://ваш-адрес`) и нажать
«Включить синхронизацию». Платформа покажет ключ класса — его вводят на других
устройствах кнопкой «Подключить устройство к классу».

Чтобы учителям не приходилось вписывать адрес руками, задайте его один раз в
`js/sync.js`, в константе `SYNC_SERVER`.

## Переменные окружения

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `SOBERIKOD_DB` | `sync.db` рядом со скриптом | путь к базе |
| `SOBERIKOD_ORIGINS` | `*` | домены, которым разрешены запросы, через запятую |

В рабочем режиме стоит сузить: `SOBERIKOD_ORIGINS=https://linnnasev.github.io`

## API

| Метод | Путь | Что делает |
|---|---|---|
| `GET` | `/api/health` | проверка живости |
| `POST` | `/api/class` | создать слот, вернуть ключ (`{"data": {...выгрузка класса...}}`) |
| `GET` | `/api/class/{id}` | прочитать класс, заголовок `X-Sync-Token` |
| `PUT` | `/api/class/{id}` | записать класс: `{"data": ..., "version": N}` |

Запись проверяет версию: если класс уже перезаписали с другого устройства, ответ
`409` со свежим номером версии, и браузер повторяет цикл «прочитать → слить → записать».
Слияние считает браузер той же функцией, что и при загрузке класса из файла, —
по каждому уроку остаётся лучший результат.

## Что сервер знает о детях

Ровно то, что лежит в выгрузке класса: имена детей, их звёзды, реакции на уроки и
сохранённые работы. Это персональные данные, поэтому:

- ставьте сервер на российский хостинг и под HTTPS;
- доступ к классу даёт только ключ (16 знаков идентификатора + 24 знака секрета),
  перебрать его нельзя, но и восстановить при потере тоже — выдайте новый;
- ключ знает учитель, он же решает, какие устройства подключать;
- удаление ученика на одном устройстве не удаляет его на других: слияние только
  добавляет. Чтобы убрать ребёнка из класса везде, удалите его и нажмите
  «Синхронизировать» на каждом устройстве, либо выключите синхронизацию и включите заново.
